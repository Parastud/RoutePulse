# RoutePulse – Smart Bus Management System

RoutePulse is a React.js-powered smart bus management dashboard built for real-time route monitoring. Developed during Smart India Hackathon 2024, where the team secured Finalist rank among 1000+ participating teams nationwide.

---

## ✨ Features

- 🚌 Real-time bus route monitoring and tracking dashboard
- 📊 Reusable data visualization components for operators
- 🔗 Multi-API integration for live data feeds
- ⚡ 30% improvement in route efficiency via optimized scheduling
- 👥 Built collaboratively by a cross-functional team of 4

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React.js |
| Backend | Node.js |
| Database | MongoDB |


## 🚀 Getting Started

### Prerequisites

- Node.js >= 18
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Parastud/RoutePulse.git
cd RoutePulse
```

### Running the Frontend

```bash
cd frontend
npm install
npm start
```

### Running the Backend

```bash
cd Backend
npm install
node index.js
```

### Environment Variables

Create a `.env` file inside the `Backend/` directory:

```env
MONGO_URI=your_mongodb_connection_string
PORT=5000
```
